# Changelog

## 1.0.0 — 2026-10-18

First public release of SymmClimateNet.

- Freezes the Stage-B selected symmetric-spatial architecture.
- Adds a clean public Python API and command-line metadata inspection.
- Archives Stage-B lock, Stage-C frozen benchmark, and Stage-D external-source summary evidence.
- Adds GitHub Actions for testing and PyPI Trusted Publishing.
- Does not redistribute raw climate observations or pretrained checkpoints.
